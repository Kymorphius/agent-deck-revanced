# 会话搜索范围

<!-- matrix/hardened: separate candidate scope from the view used to reveal a result. -->
这三种入口搜索当前 profile 已管理的本机会话，匹配标题、分组、项目路径和工具，支持 `agent deck` 匹配 `agent-deck`、`adk` 等顺序缩写。

| 快捷键 | 搜索范围 | 回车定位 |
| --- | --- | --- |
| `/` | 全部本机会话，包含归档会话 | 清除状态、时间、置顶、最近和分组范围等视图筛选，再展开目标分组并定位 |
| `Alt+?`，即 `Alt+Shift+/` | 当前视图及其筛选条件下的本机会话 | 保持当前视图和筛选，展开并定位其中的结果 |
| `Alt+/` | 当前选中分组的直属本机会话 | 清除挡住目标的视图筛选，再展开并定位该组中的结果 |

macOS 使用 `Option` 代替 `Alt`，兼容普通 Option 模式产生的 `¿` 和 `÷`。快捷键在会话列表中生效。当前分组由光标选中的分组、会话或窗口确定；没有选中本机分组时，`Alt+/` 会说明原因并打开全部本机会话搜索。

搜索框底部明确显示“全部本机会话”“当前视图”或“当前分组”。当前视图的集合包含折叠组里的匹配会话，不限于屏幕上当前露出的行；状态、归档、时间、置顶、最近交互和分组范围会组合生效。后台刷新继续应用打开时的范围并保留关键词。

打开搜索和按 `Esc` 取消不会清除主列表筛选。选择全部搜索或分组搜索的结果后才调整视图；归档结果切换到归档列表，保留会话的归档状态。搜索期间被删除、移出分组或不再符合当前视图的结果会提示重新搜索，不会跳到相邻条目。

`Alt+?` 可通过 `[hotkeys].view_search` 重绑，空字符串表示禁用：

```toml
[hotkeys]
view_search = "alt+?"
```

`Alt+S` 是单独的[分组名称搜索](group-search.md)。`G` 和搜索中的 `Tab` 打开 Recall 全文搜索，`Alt+R` 限定已管理会话的全文内容；Recall 中已管理结果的定位同样会清除挡住目标的视图筛选。
